# Lazy Strava

Create fake Strava activity results for Instagram stories. Flex without the sweat.

## What it does

- Customize activity details (run, ride, swim, hike): distance, time, pace, elevation
- Add your own background photo or use the placeholder
- Position and resize stats with multiple styles (Map + Stats or Compact)
- Export at 1080×1920 (Instagram story size)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — run production build
- `npm run lint` — run ESLint

## Tech

Next.js (App Router), React 19, TypeScript, Tailwind CSS 4.
